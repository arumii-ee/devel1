# 냉장고

냉장고 재료와 유통기한을 관리하는 웹앱입니다. HTML · CSS · JavaScript만 사용했고 설치나 빌드가 필요 없습니다.

## 기능
- 재료 등록: 이름, 수량·단위, 보관 위치(냉장 / 냉동 / 실온), 유통기한(선택)
- 유통기한이 가까운 재료가 맨 위로 올라오고 색으로 표시
  - 🔴 지남 · 🟠 임박(2일 이내) · 🟡 7일 이내 · 🟢 여유 · 회색 기한 없음
- 상단 경고 배너, D-day 배지(`D-3`, `오늘까지`, `D+1`) (다 떨어진 재료는 경고에서 빠지고 같은 색 그룹의 맨 아래로)
- 카드에서 바로 수량 `−` / `+`, 수량 숫자를 누르면 키패드로 직접 입력
- 수량이 0이 되면 `다 떨어졌어요` 알림에서 **장보기 추가** 또는 **삭제** 선택
- 다 떨어진 재료가 있으면 목록 맨 아래 `다 떨어진 재료 N개 정리` 버튼으로 한 번에 지우기 (지금 보는 탭·검색 기준, 실행 취소 가능)
- 카드를 왼쪽이나 오른쪽으로 밀면 휴지통이 나오고, 누르면 삭제(실행 취소 가능)
- 카드를 누르면 수정
- **추천 레시피**: 가진 재료로 만들 수 있는 요리 156가지(한식·중식·일식·양식·간식) 중에서 추천
  - 종류 탭(국·찌개 / 반찬 / 메인요리 / 밥·덮밥 / 면·파스타 / 간식·브런치)으로 골라 보기 (선택은 이 기기에 기억)
  - "바로 만들 수 있어요" / "재료 1~2가지만 더 있으면"으로 나눠 표시
  - 유통기한이 급한 재료를 쓰는 요리를 먼저 보여줌
  - 요리를 누르면 기본 양념과 만드는 순서 표시
- **메모 · 장보기**: 상단 `메모` 버튼 화면 위의 탭으로 `메모` / `장보기 N`(아직 안 산 개수)을 전환 (마지막 탭은 이 기기에 기억)
- **장보기 목록**: 살 것을 적고, 산 것은 체크 (줄이 그어지고 `산 것` 아래로)
  - 체크하면 나오는 `냉장고에 넣기`를 누르면 이름이 채워진 재료 추가 창이 열림
  - 연필 버튼으로 이름 고치기, 휴지통 버튼으로 지우기, `산 것 지우기`로 한 번에 정리 (모두 실행 취소 가능)
  - 아직 안 산 같은 이름은 두 번 들어가지 않음, 항목마다 넣은 날짜·사람(산 것은 산 날짜·사람) 표시
  - 가족 공유 중에는 가족 모두에게 실시간으로 보이고 누구나 체크·수정 가능
- **메모**: `메모` 탭에서 메모를 남기고, 연필 버튼으로 고치고, 휴지통 버튼으로 지우기 (실행 취소 가능)
  - 메모마다 남긴 날짜·시간과 남긴 사람 표시 (혼자 쓸 때는 `나`), 고친 메모에는 `수정됨` 표시
  - **댓글**: 메모 아래 `댓글 달기`로 댓글을 남기고 `수정` · `삭제` 가능 (삭제는 실행 취소 가능)
  - 가족 공유 중에는 가족 모두에게 실시간으로 보이고, 가족 누구나 메모·댓글을 고치고 지울 수 있음 (다른 사람이 고치면 `수정됨 · 이름` 표시)
- 위치별 탭 필터, 검색 (초성 검색 가능: `ㅇㅇ` → 우유, `ㄷ부` → 두부)
- 정렬 선택: 유통기한순(기본) · 이름순 · 등록순, `↑`/`↓` 버튼으로 오름차순 · 내림차순 전환 (선택은 이 기기에 기억, 유통기한순에서 다 떨어진 재료는 방향과 상관없이 그룹 맨 아래)
- 같은 이름·보관 위치·단위의 재료를 추가하거나, 수정해서 같게 만들면 기존 재료에 수량을 합칠지 물어봄 (유통기한은 더 빠른 날짜로, 가족 공유 중엔 등록한 사람 이름이 최근에 넣은 사람으로 바뀜)
- 휴대폰 화면 기준 디자인, 다크 모드, 안드로이드 뒤로가기 버튼 지원
- **앱으로 설치**(PWA): 홈 화면 아이콘, 전체 화면 실행, 인터넷 없이도 실행
- **가족 공유**: 가족 코드(예: `K7PM-3QXA-B2CD`)를 입력한 휴대폰끼리 목록이 실시간으로 함께 바뀜
  - 누가 넣은 재료인지 이름 표시, 인터넷이 끊겨도 쓰고 연결되면 자동 전송
  - 멤버만 접근, 관리자의 내보내기·코드 바꾸기
  - 가족 메모도 함께 공유 (마지막 멤버가 나가면 함께 삭제, 혼자 쓰던 메모는 기기에 그대로)
  - 가족 장보기 목록도 함께 공유 (혼자 쓰던 장보기 목록은 메모처럼 기기에 그대로)
- **데이터 백업**: 사람 모양 버튼 화면 맨 아래 `파일로 저장` / `파일 불러오기`
  - 재료 · 메모 · 장보기 목록을 `fridge-backup-날짜.json` 파일로 저장
  - 불러오기는 지금 목록에 **없는 것만 더함** (지우거나 덮어쓰지 않음, 형식이 맞지 않는 항목은 건너뜀). 가족 공유 중이면 가족 목록에 더해짐
- 가족 공유를 켜지 않으면 데이터는 이 기기의 브라우저(localStorage)에만 저장 (브라우저 데이터를 지우기 전에 백업해 두세요)

## 앱으로 설치하기 (카카오톡처럼 아이콘으로 실행)

설치하면 홈 화면·앱 서랍에 **냉장고** 아이콘이 생기고, 주소창 없이 전체 화면으로 열리며, 인터넷이 없어도 실행됩니다.
아이콘을 길게 누르면 **재료 추가 / 추천 레시피** 바로가기도 나옵니다.

### 1. 앱 주소 만들기 (처음 한 번)
1. GitHub 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: `main`, 폴더: `/ (root)` → **Save**
3. 1~2분 뒤 위쪽에 나오는 주소가 앱 주소입니다: `https://arumii-ee.github.io/devel1/`

### 2. 갤럭시 휴대폰에 설치
- **Chrome**: 앱 주소 열기 → 화면 위 **"앱으로 설치하기"** 누르기
  (안 보이면 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가 → 설치**)
- **삼성 인터넷**: 앱 주소 열기 → 주소창의 설치 아이콘(⬇) 또는 아래 메뉴 ≡ → **현재 페이지 추가 → 홈 화면**

### 3. 윈도우 PC에 설치
- **Edge / Chrome**에서 앱 주소 열기 → 주소창 오른쪽 **설치 아이콘(⊕)** → 설치
  → 시작 메뉴·바탕화면에 앱이 생깁니다.
- 설치 없이 보기만 하려면 내려받은 폴더의 `index.html`을 더블클릭해도 됩니다(이 경우 오프라인 저장·설치 기능은 빠짐).

### 업데이트
앱을 고쳐 GitHub에 올리면, 인터넷이 연결된 상태로 앱을 다음에 열 때 자동으로 새 버전이 적용됩니다.
가족에게는 앱 주소만 보내 주면 각자 설치할 수 있습니다.

> 가족 공유를 켜기 전에는 기기마다 따로 저장됩니다. PC와 휴대폰, 가족끼리 같은 목록을 보려면 아래 "가족 공유 설정"을 한 번 해 주세요.

## 가족 공유 설정 (처음 한 번, 관리하는 사람만)

가족 공유는 구글의 무료 온라인 서비스 **Firebase**(익명 로그인 + Firestore 데이터베이스)를 씁니다. 가정용 사용량은 무료 요금제(**Spark**) 안에 충분히 들어갑니다. **Blaze(종량제)로 바꾸지 마세요** — Spark는 카드 등록이 없어 요금이 나올 수 없습니다.

1. **프로젝트 만들기**
   [Firebase 콘솔](https://console.firebase.google.com)에 구글 계정으로 로그인 → **프로젝트 추가** → 이름(예: `my-fridge`) 입력. Google 애널리틱스는 꺼도 됩니다.
2. **익명 로그인 켜기**
   왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법(Sign-in method)** → **익명(Anonymous)** → 사용 설정 → 저장
3. **앱 주소 허용하기**
   같은 Authentication 화면 **설정(Settings) → 승인된 도메인(Authorized domains) → 도메인 추가** → `arumii-ee.github.io` 입력
4. **데이터베이스 만들기**
   **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치: `asia-northeast3 (서울)` 추천
   - 시작 모드: **프로덕션 모드**
5. **보안 규칙 붙여 넣기**
   Firestore 화면의 **규칙** 탭 → 내용을 모두 지우고 이 저장소의 [`firestore.rules`](firestore.rules) 내용을 붙여 넣기 → **게시**
6. **웹 앱 등록**
   프로젝트 개요 옆 톱니바퀴 → **프로젝트 설정 → 일반 → 내 앱 → 웹(`</>`)** → 앱 닉네임 입력 → 등록
   화면에 나오는 `const firebaseConfig = { ... }` 안의 내용을 복사
7. **설정값 붙여 넣기**
   [`js/firebase-config.js`](js/firebase-config.js)의 `FIREBASE_CONFIG` 값을 복사한 값으로 바꾸기 (이 저장소에는 이미 설정되어 있음)
   ```js
   var FIREBASE_CONFIG = {
     apiKey: "AIza...",
     authDomain: "my-fridge.firebaseapp.com",
     projectId: "my-fridge",
     storageBucket: "my-fridge.appspot.com",
     messagingSenderId: "1234567890",
     appId: "1:1234567890:web:abcdef"
   };
   ```
   GitHub 웹사이트에서 파일을 열고 연필(✏️) 버튼으로 바로 고쳐도 됩니다.
8. **GitHub에 올리기** → 앱 주소로 연(설치한) 모든 휴대폰에 적용됩니다.

**(선택, 더 안전하게) API 키 사용처 제한**
[Google Cloud 콘솔 → API 및 서비스 → 사용자 인증 정보](https://console.cloud.google.com/apis/credentials)에서 `Browser key (auto created by Firebase)` → **애플리케이션 제한: 웹사이트** → `https://arumii-ee.github.io/*` 추가 → 저장. 다른 사이트에서 이 키를 가져다 쓰지 못하게 됩니다.

> `apiKey`는 비밀번호가 아니라 "어느 Firebase 프로젝트인지" 알려주는 값이라 공개 저장소에 올려도 괜찮습니다.

### 가족과 함께 쓰기
1. 한 사람이 앱에서 **사람 모양 버튼 → 내 이름 입력 → 새 가족 냉장고 만들기** (이 사람이 **관리자**가 됩니다. 이 기기에 있던 재료가 함께 올라갑니다)
2. **초대하기**를 눌러 카카오톡 등으로 가족 코드(예: `K7PM-3QXA-B2CD`)를 보내기
3. 가족은 앱에서 **사람 모양 버튼 → 내 이름 입력 → 가족 코드로 참여**
4. 위쪽에 `가족 냉장고 · 실시간 동기화 중`이 보이면 연결된 것입니다.

### 보안 구조
- **멤버만 접근**: 각 기기는 익명 로그인으로 고유 번호를 받고, 가족 냉장고의 **멤버 명단에 있는 기기만** 재료를 읽고 쓸 수 있습니다.
- **가족 코드는 가입용 열쇠**: 코드는 새 멤버가 들어올 때만 쓰입니다. 12자리(약 79경 가지)라 추측할 수 없고, 다른 가족의 코드나 목록을 훑어볼 수 없습니다.
- **관리자 기능**: 멤버 **내보내기**(내보내기와 코드 바꾸기가 한 번에 처리되어, 내보낸 기기는 옛 코드로 재가입할 수 없고 새 코드도 볼 수 없음), **코드 바꾸기**(이미 들어온 가족은 그대로). 휴대폰을 잃어버렸다면 그 기기를 내보내세요.
- **관리자 자동 승계**: 관리자 기기가 **30일 넘게** 접속하지 않으면(휴대폰 분실, 앱 데이터 삭제 등) 그다음 앱을 연 가족이 자동으로 관리자가 됩니다. 새 관리자는 오래 안 쓰는 기기(`30일 넘게 안 씀` 표시)를 내보낼 수 있습니다.
- **데이터 검사**: 서버 규칙이 저장되는 모든 값의 종류·길이를 검사해, 이상한 데이터나 대량의 쓰레기 데이터를 막습니다.
- **외부 코드 차단**: Firebase 프로그램을 앱 안(`vendor/firebase/`)에 넣었고, 보안 정책(CSP)으로 허용된 곳 외의 스크립트 실행·통신을 막습니다.
- 휴대폰의 앱 데이터를 지우면 고유 번호가 바뀌므로 가족 코드로 다시 참여해야 합니다.
- **가족 공유 그만하기**: 그 기기만 빠지고 보던 목록은 기기에 복사됩니다(참여할 때 합치지 않은 이 기기 재료도 그대로 남음). 관리자가 나가면 가장 먼저 들어온 가족이 관리자가 되고, 마지막 멤버가 나가면 재료 · 메모 · 장보기와 초대 코드가 삭제됩니다. (보안 규칙상 빈 가족 정보 문서는 남지만, 코드를 새로 바꿔 두므로 아무도 다시 들어올 수 없습니다)
- 가족 공유는 앱 주소(https)에서만 됩니다. PC에서 `index.html`을 더블클릭해 연 경우에는 혼자 쓰기만 됩니다.
